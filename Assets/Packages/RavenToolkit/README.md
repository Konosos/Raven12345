# RavenToolkit

Reusable Unity Editor utilities:

- **Android Build Setting** — configure and start Android builds.
- **Define Symbols** — manage scripting define symbols for the active target.
- **Helpful Buttons** — change scenes, clear local data, and remove missing scripts.
- **Script Editor** — open and edit a C# script inside Unity.
- **ScriptableObjectCreator** — UI Toolkit control for creating/selecting ScriptableObject assets.

## Install from Git

In Unity, open **Window > Package Management**, select **Install package from git URL**, then enter:

```
https://github.com/Konosos/Raven12345.git?path=Assets/Packages/RavenToolkit
```

Use a tag or commit for a fixed version, for example `https://github.com/Konosos/Raven12345.git?path=Assets/Packages/RavenToolkit#v1.0.0`.

## Requirements

- Unity 6000.0 or newer.
- Android build support is required only for **Android Build Setting**.

## Menus

- `Tools/Raven/Android Build Settings`
- `Tools/Raven/Define Symbols`
- `Tools/Raven/Helpful Buttons`
- `Tools/Raven/Script Editor`
