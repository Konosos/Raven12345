# Service Container

## Installation

Add the package through Unity's **Package Manager** using the following Git URL:

```text
https://github.com/Konosos/Raven12345.git?path=Assets/Packages/ServiceContainer
```

## Setup

1. Create a ScriptableObject class named `ServiceGlobalSettingSO` that inherits from `ServiceSettingSO`.
2. Create an instance of `ServiceGlobalSettingSO` inside a `Resources` folder.
