# Changelog

All notable changes to this package are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-20

### Added

- Global and scene-scoped service containers.
- Service registration by concrete type or implemented interfaces.
- Lazy singleton, prefab, resource, and transient service creation.
- `SceneInstaller` support for component registrations and scene-specific `ServiceSettingSO` assets.
- `ServiceGlobalSettingSO` support for registering multiple global service settings from a `Resources` asset.
- Git URL installation and setup instructions.
